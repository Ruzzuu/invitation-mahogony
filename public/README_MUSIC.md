# Cara menambahkan musik

Letakkan file musik wedding kamu di sini dengan nama:

  public/music.mp3

Contoh sumber musik gratis untuk wedding:
- https://pixabay.com/music/search/romantic/
- https://www.bensound.com (download manual, jangan hotlink)
- https://freemusicarchive.org

Setelah meletakkan file di sini, musik akan otomatis berjalan saat tamu membuka undangan.
